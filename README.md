# Quote & Invoice Maker

A phone app for making quotes and invoices, with automatic totals and PDF export. It works on Android and iPhone and installs to the home screen.

## Features
- Your own logo, company details, banking details and brand colour
- Quotes and invoices with line items, headings, automatic totals and a VAT on/off switch
- Automatic numbering in your own format, e.g. `{n}/{yy}` → 12/26
- Turn a quote into an invoice with one tap
- A4 PDF export that opens the share sheet on phones, for WhatsApp or email
- Status tracking (Draft, Sent, Accepted, Paid…) and search
- Works offline once opened

## Where data is kept
Everything stays on the phone it was entered on, in the browser's storage. Nothing is sent to a server. Each business uses its own phone and gets its own private data.

Use **Business details → Download backup** regularly. A backup file can be restored on a new phone.

## Install on a phone
- **Android (Chrome):** open the site, then tap **Install** in the app (or **⋮ → Add to Home screen**).
- **iPhone (Safari):** open the site, tap **Share → Add to Home Screen**.

## Hosting
A static site with no build step, served by GitHub Pages from the `main` branch root.
